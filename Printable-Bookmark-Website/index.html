Printable-Bookmark: the herbarium press catalogue

A catalogue page for the keeper's desk: a small Python script that collects the pin pages of one Pinterest board and saves them as printable bookmark material.

What it is

Printable-Bookmark is a small Python utility that collects every pin from one Pinterest board and downloads the pin pages for use as printable bookmark material. You point it at a single board, press it once, and the pages come down into a local folder, ready to print, cut, and slip between the pages of a book.

How it works

Run it from the repository root:

python3 main.py

  • The script reads the single BOARD_URL constant near the top of main.py and fetches that board's page.
  • It finds every pin link on the page with BeautifulSoup, matching the anchor class GrowthUnauthPinImage, and keeps the unique pin URLs.
  • Each pin page is fetched and saved into the folder named by the FOLDER variable, under the last segment of its URL.
  • Only successful saves are counted; the run ends by reporting how many pages were pressed into the folder.

Requirements

  • Python 3
  • The only third party libraries are requests and beautifulsoup4. Install them with pip install requests beautifulsoup4.

Keeper notes

  • Every request carries a 15 second timeout, so a slow board cannot hang the press indefinitely.
  • Saves are binary and named after the last segment of the pin URL; a re-run over the same board overwrites files with the same name rather than duplicating them.
  • The board address lives in one constant, BOARD_URL; change that one line to press a different board.
  • If the board page no longer uses the GrowthUnauthPinImage class, the script finds no pins and saves nothing; update the PIN_LINK_CLASS constant to match the page again.
  • An empty board, or a board that fails to load, surfaces as a request error or a zero count rather than a partial folder.
